## 🎯 Project Overview

This project demonstrates how an AI agent can understand a user's request, decide which tool is required, execute that tool, process the result, and generate a final response.

## 🔄 Agent Workflow

User Request → AI Agent → Tool Selection → Tool Execution → Tool Result → Final Response

## 🧠 How the Agent Works

1. The user enters a request.
2. The LLM analyzes the request.
3. The agent selects the appropriate tool.
4. The selected tool is executed.
5. The tool returns a result.
6. The result is provided back to the LLM.
7. The LLM generates the final response.

## 🧮 Example

User:

Calculate 75 * 16 and add a task called Review the calculation result.

Agent:

1. Selects the calculator tool.
2. Calculates 75 × 16 = 1200.
3. Selects the add_task tool.
4. Adds the requested task.
5. Generates the final response.
